# Problem Statement

## Problem
Freshers students often learn algorithms such as GCD, prime checking or
factorial only as formulas to memorise. They rarely see how the algorithm
works step by step, and they get few chances to practise with instant feedback.

## Scope
A console-based Python program that lets a student run core problem-solving
algorithms from the CSE1021 syllabus, see the intermediate steps, and test
themselves with a quiz. The project does not use a database, a GUI or the internet.

## Target Users
- First-year engineering / computer science students learning Python
- Anyone revising basic algorithms before a lab or exam

## High-Level Features
1. **Number Algorithms** - factorial, Fibonacci, reverse, base conversion, swap, digit counting, character to number.
2. **Factoring Methods** - GCD/LCM with steps, primes, prime factors, square root, fast power, nth Fibonacci, pseudo random numbers.
3. **Arrays and Collections** - reverse, count, min/max, remove duplicates, partition, k-th smallest, set operations, word frequency.
4. **Practice Quiz** - random questions generated from the algorithms, with scoring.
5. **Session History and Logging** - dictionary-based usage summary and a log file.
